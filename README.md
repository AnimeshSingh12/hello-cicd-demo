# Hello CI/CD Demo

A small C++ project for learning and testing GitHub Actions CI/CD and GitHub Releases.

## What this project does

1. GitHub Actions checks out the repository.
2. `Setting.toml` is read as the single source of truth for configurable values.
3. The C++ program is compiled on an Ubuntu GitHub runner.
4. The program runs and generates `hello.txt`.
5. The generated file is uploaded as a workflow artifact.
6. Pushing a tag such as `v1.0.0` starts the release workflow.
7. The release workflow builds and runs the application and creates a GitHub Release containing `hello.txt`.

## Repository structure

```text
hello-cicd-demo/
├── .github/
│   └── workflows/
│       ├── flow.yml
│       └── release.yml
├── config/
│   └── Setting.toml
├── src/
│   └── main.cpp
└── README.md
```

## Test the CI flow

Push a commit to `main` or open a pull request against `main`.

Then open **Actions → CI Flow** in GitHub.

The workflow should compile and execute the program and upload `hello.txt` as an artifact.

## Test a GitHub Release

Create and push a tag:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Then open **Actions → Release**.

After the workflow succeeds, open **Releases** in the repository. A release named `Hello Generator Release v1.0.0` will contain `hello.txt`.

## Local test

```bash
g++ -std=c++17 src/main.cpp -o hello_generator
./hello_generator
cat hello.txt
```

Expected output file content:

```text
Hello! The file is generated by C++ running on GitHub Actions.
```
